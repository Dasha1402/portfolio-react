# Личное портфолио — Дарья Лапина

Одностраничный сайт-визитка Frontend-разработчика: обо мне, проекты, контакты.

🔗  **Демо:** https://dasha1402.github.io/portfolio-react/

## Что реализовано

- **Тёмная и светлая тема.** Кнопка в шапке переключает состояние `isDark`, в `<html>` меняется атрибут `data-theme`, цвета заданы через CSS-переменные.
- **Анимации при прокрутке.** Блоки плавно появляются при попадании в область видимости (Framer Motion, `whileInView`).
- **Мокап браузера на чистом CSS.** Компонент `BrowserMockup` рисует рамку окна браузера без картинок, внутри — слайдер со скриншотами проектов.
- **Адаптивное бургер-меню.** На мобильных устройствах состояние `isMenuOpen` раскрывает меню со ссылками.
- **Данные проектов** вынесены в файл `projects.ts`.

## Стек

React, TypeScript, Vite, Framer Motion, деплой через gh-pages.

## Запуск локально

```bash
git clone https://github.com/Dasha1402/portfolio-react.git
cd portfolio-react
npm install
npm run dev
```
